1. Introduction					*kitty-scrollback-intro*

kitty-scrollback.vim opens kitty's scrollback (`show_scrollback`, by default
ctrl+shift+h) in Vim so it looks exactly like the screen you were just on:

- every cell keeps kitty's colors and attributes, using the palette that
  kitty actually has right now, including true color, dim text, reverse
  video, strikethrough and all underline styles and colors
- the first line on kitty's screen is the first line in Vim, also when kitty
  was scrolled back
- the cursor sits on the same cell it was on in kitty

The pager runs with its own vimrc and without any plugins, so neither your
vimrc nor other plugins can change how the scrollback looks.

==============================================================================
2. Setup					*kitty-scrollback-setup*

When Vim starts inside kitty and a kitty.conf exists, the plugin checks
whether kitty's `scrollback_pager` uses it. If not, it asks whether it should
configure kitty:

	Yes		Sets `scrollback_pager` in kitty.conf and makes kitty
			reload its configuration.
	No		Does nothing, you will be asked again next time.
	Never ask again	Does nothing and stops asking.

Nothing happens outside of kitty, in the GUI, or when no kitty.conf exists.
kitty.conf is looked up like kitty does it: in $KITTY_CONFIG_DIRECTORY when
it is set, otherwise in $XDG_CONFIG_HOME/kitty (~/.config/kitty) and on macOS
also in ~/Library/Preferences/kitty. `include` and `globinclude` are followed
to find the setting that is actually in effect.

When configuring, kitty.conf is first copied to kitty.conf.{timestamp}.bak.
Existing `scrollback_pager` lines are commented out and the new one is added
at the end of the file, so no `include` can override it.

						*:KittyScrollbackSetup*
:KittyScrollbackSetup
	Check and configure kitty right now, also after "Never ask again".
	Reports what it found when nothing needs to be done.

The setting it writes looks like this: >
	scrollback_pager vim -N --not-a-term
	    \ -u ~/.vim/plugged/kitty-scrollback.vim/pager.vim
	    \ -c "KittyScrollback INPUT_LINE_NUMBER CURSOR_LINE CURSOR_COLUMN" -
<(on one line). The Vim that ran the setup is used, written as just "vim" when
that is the one found in $PATH.

==============================================================================
3. Usage					*kitty-scrollback-usage*

Open the scrollback with kitty's `show_scrollback` action. A purple
SCROLLBACK label and the line position are shown in the bottom row, which Vim
needs for its command line anyway.

	q, i		Close the pager.
	y		Yank as usual. Everything yanked is also copied to the
			system clipboard through kitty (OSC 52), which needs
			`write-clipboard` in kitty's `clipboard_control`. This
			also works over ssh.

Everything else is normal Vim. 'virtualedit' is "all", so the cursor can be
anywhere a terminal cursor can be, also past the end of a line.

==============================================================================
4. How it works					*kitty-scrollback-internals*

kitty pipes the scrollback with its escape codes into the pager. Instead of
replaying it in a |:terminal|, the pager removes the escape codes and turns
the SGR attributes into |text-properties|. This way no colors are re-mapped
and there is no wait for a terminal job to finish.

Palette colors are then asked from kitty (OSC 4, 10, 11, 17 and 19) and
applied as soon as the answers come in. They are cached in
$XDG_CACHE_HOME/kitty-scrollback.vim/colors.json, so the first frame already
has the right colors from the second time on. The opacity of dim text is
read from `dim_opacity` in kitty.conf.

INPUT_LINE_NUMBER is the first line on kitty's screen. As kitty's last screen
row is the last line of the input and the pager has the size of kitty's
window, the cursor line follows from CURSOR_LINE. When the cursor is on
kitty's last row, the view moves up by one line, as Vim always keeps the last
row for its command line.

==============================================================================
5. Configuration				*kitty-scrollback-config*

						*g:kitty_scrollback_check*
g:kitty_scrollback_check	boolean (default: true)
	Set to false to never check kitty's configuration on startup.
	|:KittyScrollbackSetup| still works. >
		g:kitty_scrollback_check = false
<
==============================================================================
6. Tab title					*kitty-scrollback-tab-title*

kitty names the pager window "History", and that title can't be changed
from inside the pager. To show something else in the tab bar, test for it in
kitty's `tab_title_template`, for example: >
	tab_title_template "{fmt.fg._b3a1e6 + fmt.bold + 'scrollback'
	    \ + fmt.nobold + fmt.fg.tab if title == 'History' else title}"
<(on one line).
