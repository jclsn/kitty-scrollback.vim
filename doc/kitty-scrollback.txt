*kitty-scrollback.txt*	Vim as kitty's and tmux's scrollback pager

Requires Vim 9.1 with |+vim9script|, |+textprop| and |v:termosc|, tmux 3.2.

						*kitty-scrollback*
kitty's `show_scrollback` key (ctrl+shift+h) opens the scrollback in Vim with
its colors, view and cursor as on screen. In tmux, also behind ssh, the same
key shows the current pane's history in a popup.

	q, i	Close the pager.
	y	Yank, also to the clipboard: OSC 52 in kitty (needs
		`write-clipboard` in `clipboard_control`), a tmux buffer in tmux.

						*:KittyScrollbackSetup*
:KittyScrollbackSetup
	Adds the settings below to kitty.conf, and to tmux.conf when run in
	tmux, and loads them. The old file is kept as {file}.bak. For tmux on
	another machine, install the plugin there and run it there too.

kitty.conf (each setting on one line): >
	scrollback_pager vim -N --not-a-term
	    \ -u ~/.vim/plugged/kitty-scrollback.vim/pager.vim
	    \ -c "KittyScrollback INPUT_LINE_NUMBER CURSOR_LINE CURSOR_COLUMN" -
	map --when-focus-on var:kitty_scrollback_tmux kitty_mod+h
	    \ send_text all \x1b[4242~
<tmux.conf: >
	set -as terminal-overrides ',*:smcup=\E[?1049h
	    \ \E]1337;SetUserVar=kitty_scrollback_tmux=MQ==\007
	    \ :rmcup=\E]1337;SetUserVar=kitty_scrollback_tmux\007\E[?1049l'
	set -s user-keys[42] "\e[4242~"
	bind -n User42 run -C "display-popup -B -E -x P -y P
	    \ -w #{pane_width} -h #{pane_height} -d '#{pane_current_path}'
	    \ \"vim -N --not-a-term
	    \ -u ~/.vim/plugged/kitty-scrollback.vim/pager.vim
	    \ -c 'TmuxScrollback #{pane_id}'\""
<While a tmux client is attached, the user variable kitty_scrollback_tmux is
set in kitty, so the scrollback key sends tmux User42 instead.

The terminal's colors are cached in
$XDG_CACHE_HOME/kitty-scrollback.vim/colors.json.
